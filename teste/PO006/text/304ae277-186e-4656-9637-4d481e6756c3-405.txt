    12. ORIGINE DES PROPHÈTES. — Écoute aussi cet exposé-ci. Les prophètes,
    d'une part, les apôtres, d'autre part, sont sortis de Jacob. La maison d'Israël
    a été appelée (un troupeau de) moutons, comme dit Hénoch : De l'âne du désert
    est né le bœuf, c'est-à-dire Abraham de Tárá. Le bouc est né * du bouc, c'est-à-dire
    Jacob d'Isaac. Quant à Ésaü, il l'a appelé sanglier. Le prophète Hénoch a
    dénommé les divers peuples : les Amalécites : aigles; les Égyptiens : hyènes;
    les Ismaélites : ânes du désert; les Arabes : boucs; les Cananéens : corbeaux; les
    Philistins : renards; les Moabites : souris; les Perses : lions; les Ammonites :
    scorpions; les Madianites : serpents; les descendants de Japhet : léopards; les
    Édomites : loups. Le prophète Hénoch a dénommé tous les divers (peuples), (lui)
    qui a écrit l'exposé (des événements) futurs, avant qu'ils n'arrivent. Je vais
    encore maintenant parler des prophètes. L'Apôtre a dit : Le premier de tous
    * les prophètes est Adam, notre père. Sa mère est la terre. Son père est le Seigneur,
