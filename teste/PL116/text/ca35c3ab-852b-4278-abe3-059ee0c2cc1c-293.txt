    IN PSALMUM CXIII.
    TITULUS. Alleluia.
    
    ( In exitu Israel. ) In hoc psalmo loquitur propheta, et habet materiam beneficiû Dei, quæ fecit Ecclesiæ, significata per illâ beneficiâ quæ contulit antiquo populo. Dicuntur enim hic quædam quæ nos ab historia removerent; sicut : « Montes exsultaverunt et colles. ) In prima parte, proponit nobis beneficia quæ Deus facit Ecclesiæ, per figuras eas significans. In secunda, quæ incipit : ( Quid est tibi, mare, qui fugisti, ) facit quaestionem, quasi admirans : Quis potest facere populo suo tanta beneficia ? Et solvit eam, ostendens a Domino esse factam : non tamen quod propheta miretur, sed nobis admirandum esse relinquitur de bonitate Dei. In tertia parte, quæ incipit : ( Simulacra gentium, ) facit collationem de cultura deorum falsorum, gentium scilicet, et Christianorum : ostendens gentium culturam esse stultitiam Christianorum autem esse utilissimam. Intendit nos admonere ut pro beneficiis illis in nobis complexis, Alleluia Domino decantemus, et ut ex historia trahamus allegoriam.
    
    Prius legamus historiam, sic : « In exitu Israel de Ægypto, ) id est, quando Israeliticus populus exivit de Ægypto, scilicet de exitu domus, ) id est totius familiæ Jacob. De Ægypto, de qua exivit merito, quia scilicet a populo barbaro, ) id est, quia populus erat barbarus.
    
    In exitu illo ( Judæa ) terra illa est facta sanctificata illius populi; quia ibi potuerunt ceremonias illas et sacrificia Deo persolvere, in quibus ibi populi sanctificabantur; et Israel ( est factus ) potens status ejus, terrae, id est, potens in terra illa : et tunc apparuit Judæa quasi domina omnium terrarum.
    
    Et quomodo exivit? Per hoc quod ( mare ) Rubrum vidit, ) id est, cognovit, faciem Dei et voluntatem, et fugit ( mare, ) id est, divisit seipsum : et quando venerunt ad Jordanem, tunc ( Jordanis conversus est retrorsum, ) quia faciet eis viam.
    
    Et cum venerunt in Judæam, ( montes, ) id est, altiores in populo, ut Josue et Caleph, ) exercitaverunt ut arietes, et colles, ) id est, minores in populo, id est agni ovium.
    
    Ad allegoriam: Per Israel, populum Christianum intelligimus, qui bene justificatur Israel, id est, videns Deum per fidem; quando exiit de Ægypto, id est, de tenebris infidelitatis.
