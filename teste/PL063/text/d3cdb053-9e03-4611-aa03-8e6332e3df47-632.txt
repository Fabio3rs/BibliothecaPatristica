CAPUT VI.
Ratio superioris digestae descriptionis.

Tria igitur tetrachorda tali nobis ratione descripta sunt. Tetrachordum enim omne diatessaron retinet consonantiam. Igitur nete hyperboleon, et nete diezeugnemon in tribus generibus, i. e., vel in diatono, vel in chromate, vel in enharmonia diatessaron continent symphoniam. Diatessaron autem consonantia constat duobus tonis et semitonio minore. Id hoc modo per tria genera in supradictis tetrachordis divisum est. In diatonico enim genere, quod est primum paranete hyperboleon, id est 2592, ad neten hyperboleon, id est 2304, obtinet distantiam tonum, quod tali notula inscripsimus [ilegivel]. Rursus trite hyperboleon diatonici generis, quae est 2916, ad paranete hyperboleon diatonici generis, quae est 2592, rursus obtinet differentiam quam simili nota insignivimus [ilegivel]. Nete autem diezeugnemon ad trite hyperboleon, id est 3072 ad 2916, semitonium refert, quod tali nota signavimus [ilegivel]; hoc est totum spatium nete diezeugnemon, et nete hyperboleon duorum tonorum.

CAPUT VII.
Monochordi netarum diezeugnemon per tria genera partitio.

Nete igitur diezeugnemon, quæ est 3072, si dimidium sumam, erunt 1536. Qui eisdem additi sunt 4608, quæ est mese, quam 0 littera designavimus; quod si eisdem nete diezeugnemon, id est DD scilicet 3072, auferam tertiam partem, erunt 1024. Qui eisdem conjuncti facient 4096 quæ vocabitur paramesc. X littera subnotata. Nete igitur diezeugnemon non, id est 3072, ad mesen, id est 4608, quoniam in sequenti literâ comparatione consistit, aperte consonant symphoniam. Eadem vero nete diezeugnemon, id est 3072, ad paramesen, id est 4096, quæ ad eam in sesquitera proportione composita est, diatessaron retinet consonantiam. Si igitur ad ex qui est nete diezeugnemon 3072 octavam auferam partem, — vero.
