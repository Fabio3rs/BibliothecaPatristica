CAPUT XLVII.

Per cathetum basim invenire.

Per cathetum basim invenire si vis, cathetum ipsum ducas in se, id est 5, qui sunt 25. Ex his uno dempto reliqui 24 dimidium sumas, id est 12, quod erit basis. Huic vero adjicias unum superius demplum, et invenies hypotenusam.

Embadì autem pedes invenire cupiens, basim per cathetum, id est 12 per 5 ducas, fient 60. Hujus sumpta dimidia id est 30, erit embadum.

Trapizetici embadum invenire.

Trigoni isopleri, cujus sunt singula latera 30, embadi pedes comprehendere.

CAPUT L.

Trigoni isoscelis cathetum invenire vel embadum.

Trigoni isoscelis (Cod., isoscelis), cujus singula latera sunt pedum 25, basis vero 14, si cathetus quaeratur, vel embadum. Uno latere in se duco, id est 25, fient 625. His si subduxeris dimidium basis in se 49, reliqui, id est 576 sumas latus, id est 24, et tot pedum erit cathetus. Quo per basis dimidium multiplicato, invenies embadi numerum 169.

CAPUT LI.

Trigoni scaleni cathetum invenire.

Trigoni scaleni, cujus minus latus sit pedum 15, basis 25, majus latus 20, cathetum invenire hæc erit regula : minore latere in se multiplicato, id est 15 fient 225, basi vero, id est 25, erunt 625. His utrinque summulis in unum junctis fient 850. Quibus si subduxeris majus latus in se, id est 400 ; ex reliquo, qui superfuierit, id est 450, sume dimidium, id est 225, eodem numero denominatan accipias partem, quo superscribitur basis, id est 25. Dico numeri invenies, et tot pedum erit minor præcisura, qua in se multiplicata fiet 81. Quos si subduxeris de minoris lateris in se multiplicatione, id est de 225, reliqui, qui superfuerit, id est 144, latus fiet catheti numerus.
