Quid sane adjumenti conferat assertionibus tuis explanatio, qua dicis (Epilog. num. 6, sect. 2), Deum prædestinasse, id est, ante sæcula definisse certum nu- merum eorum, qui in sua impietate interituri essent. Minime video, quam refragantenuis eis potius, non ignoro. Quid est prædestinasse, id est definisse nume- rum periturorum, nisi perituiros prædestinasse, id est definisse. Si ergo prædestinavit, id est definitiuit nu- merum peritruorum, præsciuit utique perituiros : quid autem pejus aut perniciosius creaturis rationalibus diu- ti potest, quam perire? Qui ergo præscivit perituiros, malum utique præscivit : malum est enim et omni malo deterius perire. Si, inquam, prædestinavit, id est, definitivit quor essent perituri, nullo reluctante malos malumque prædestinavit, id est definit, et ubi est astructio tua, qua tantopere nisus es affirmare; Deum nec præscisse, nec prædestinasse malum, quod est pœna, atque supplicium : nunquam enim prædesti- nare, id est definire posset certum numeruin peri- turorum, nisi præscisset perituros.
