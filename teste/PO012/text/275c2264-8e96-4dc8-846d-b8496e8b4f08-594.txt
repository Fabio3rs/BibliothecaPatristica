Voici les bénédictions des cinq mss. : B እሁው : ስም : እግዚአ : የሱስ : ክርስቶስ : በረከተ : ጸጋ : የሁ : ምስሌ : ገብረ ... ለለመ : ፍለገ : አሜን :: O suave de nom, mon Seigneur Jésus-Christ, que la bénédiction de ta grâce soit avec ton serviteur... pour les siècles des siècles! Amen. Dans le ms. ጸጋ était primitivement écrit au lieu de ጸጋ. Nos points de suspension indiquent l'espace blanc laissé dans le ms. pour l'insertion ultérieure d'un nom propre : le nom du possesseur. C የሁ : ወምሕረተ : ለእግዚእ : ኢየሱስ : ርስቶስ : የሁ : ምስሌ : ገብረ : ግዛ : የሁ : ሥጋ : ለዓለመ : ፍለገ : አሜን :: Que la clémence et la miséricorde de Notre-Seigneur Jésus-Christ soient avec son serviteur Schāhla-Schelisé [Clémence de la Trinité] pour les siècles des siècles! Amen. D የሁ : ወምሕረተ : ለእግዚእ : መድኃ : ኢየሱስ : ክርስቶስ : የሁ : ምስሌ : ግዛ : ሕጉ : ዳዊት : ለለመ : ፍለገ : አሜን :: Que la clémence et la miséricorde de Notre-Seigneur et Notre-Sauveur Jésus-Christ soient avec notre roi David pour les siècles des siècles! Amen. Le nom du roi David n'est pas primitif: ዳዊት, David, a été ajouté sur un grattage. Comme le mot ሕጉ, notre roi, est primitif, on peut inférer que ce ms. a été la propriété d'un roi précédent.
