    iste attribuendus est David, id est Christo tendenti
    in finem, id est in victoriam quæ finis est cursus

    Hebræi habent, victori. Vel in finem, id est in per-
    severantiam ; David dico agenti pro assumptione
    matutina, id est pro resurrectione quæ contigit
    mane, in qua Deus eum assumpsit de humilitate ad
    gloriam ; de mortalitate ad immortalitatem. In He-
    braica vero translatione habetur pro cerva matutina,
    quod idem est in sententia. Quasi dicat : Agenti pro
    cerva matutina, id est pro lætitia cervæ, id est hu-
