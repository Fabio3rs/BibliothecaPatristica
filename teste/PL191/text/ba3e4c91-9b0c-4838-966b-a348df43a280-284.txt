    VERS. 8. — « Juda rex meus ; Moab olla spei
    meae. »
    Juda, [Hier., Aug., Alcuin.] id est Christus, re-
    x meus. De Juda enim natus est Christus, ideo per eum
    hic bene significatur. Unde Jacob ei benedicens, si
    figura Christi ait : Juda, te laudabunt fratres tui, etc.
    (Gen. xlix). Moab olla spei meae. Moab populus qui-
    dam est, qui descendit a Moab, quem genuit major
    filia Loth, absque patre ebrioto, per quem intelligitur
    omnis abutens lege. Sicut enim filia male usus
    patre genuerunt Moabitas, sic qui male utitur lege,
    generat mala opera, ut qui bene, bona. A male ut-
    tern utensibus lege oritur olla, id est tribulatio Ec-
    clesiae. Haec est olla fervens ab aquilone, id est a
    diabolo. Unde Jeremias : Ollum succensam ego video,
    et facies ejus a facie aquilonis (Jer. i). Unde alibi
    idem Jeremias : Ab aquilone pandetur omne malum
    (ibid.), id est a diabolo qui dixit : Ponam sedem
    meam ad aquilonem, et ero similis Altissimo (Isai.
    xiv). Ab illo ergo tribulationem olla ebullit in Ec-
    clesia ; sed Christo duce olla iniquitatis ardens fa-
    est, spei non consumptiones, quia tribulatio oper-
    tur patientiam ; patientia vero probationem ; proba-
    tio vero spem (Rom. v), cum charitas flamma in
    cordibus diffusa ardet contra ollam iniquitatis. Et
    est sensus ; Juda, id est Christus est rex meus.
    Quo regente, Moab, id est abutens lege est olla,
    quia infert tribulationem. Et haec tribulatio est spei
    meae, quia facit me plenius sperare, non deperet.
    Vel Moab ponitur pro gentibus, id est per Moab
    gentes intelliguntur. Per ollam intelligitur receptio.
    De gentibus vero, quidam sunt conversi, et hi uti
    sunt tribulatione ; alii non sunt conversi, qui alios
    urunt tribulatione. Utrique vero, scilicet urentes et
    usti sunt olla, id est receptio Christi et Ecclesiae,
    quia de ustis consolatur, de urentibus proficit. Et
    est sensus : Moab, id est gentes, scilicet vel urentes
    alios tribulatione ; vel usti sunt olla, id est receptio
    spei meae, unde mihi spes vitae est. Loquitur Ec-
