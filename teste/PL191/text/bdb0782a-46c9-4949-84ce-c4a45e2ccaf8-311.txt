    Dum discernit. [Cassiod., Aug., Cassiod.] Tertia
    pars, ubi agi de donationibus Christi ascendendis,
    qui solus potest, et non alius. Quasi dicat: Si dormi-
    alis, eritis pennæ; quasi dicat: non est nisi per
    discernementum, quia dum cœlestis, id est Christus,
    qui ascendit super omnes cœlos, discernit, dividens
    singulis gratiam prout vult, reges, id est rectores,
    super eam, columbam vel hæreditatem, id est dum
    gratia Spiritus sancti reges discernuntur, super Ec-
    clesiam. Ipsi rectores vel alii homines, dealbabu ntur
    per remissionem peccatorum, nive, id est incompa-
    rabiliter, in Selmon, id est in umbra gratiæ, quæ
    venit ex corpore Christi. Selmon enim interpretatur
    umbra, id est in gratia Spiritus sancti, quia non
    meritis suis discernuntur, sed spiritu obumbrante
    ab æstu carnis. Umbra enim gratiæ defansaculum
    nobis est contra inercitia vitiorum et carnalium con-
    cupiscentiarum, de qua ad virginem parituram ange-
    lus dicit: Virtus Altissimi obumbrabit tibi (Luc. i), id
    est umbram faciet tibi. Umbra autem est corpore et
    lumine. Lumen est Verbum; caro Christi est corpus.
    Accessit lumen corpori, id est verbum carni: Verbum
    enim caro factum est (Joan. i), et in eum credentes
    hæc umbræ protegimur, quæ de corpore Christi
