Sed cum tetrachordorum, quos quadrifisos tetrachordos, id est quatuor chordas habentes, appellamus, divisiones innumerabiles sint, septem a sunt notæ, id est cognitæ, enarmoni, scilicet generis, duæ, divisiones sunt notæ; chromatis, scilicet generis, tres, scilicet sunt divisiones notæ, quarum una prima, quæ mollis ac soluta, id est lasciva, mollis dicitur, quod tria hemitionia habet in una regione, et a ceteris regionibus absoluta, id est ampla, quam vero tria hemitionia unius spatii comparata duobus hemitionis, hemiolia ratio efficitur, ideo secunda nota hemiolia. Secunda, scilicet nota, quæ hemiolia est, scilicet quod ibi abundat sesquitertia divisio. Tertia, scilicet nota, quæ est tonica b, quod unus tonus dividitur ibi in duo hemitionia: diatonicos, scilicet generis, duæ, scilicet divisiones sunt, una mollis, scilicet propter integrum tonum, altera robusta, id est, acuta propter hemiolion. Et modos, id est species quidem accipti enarmoniæ scilicet genus, a tetarternoria diesi, id est teni parte quarta, nam μᴏρῆς pars dicitur. Illud vero quod mollius, id est, chroma diximus, per tritemorian diesin copulatur, id est, conjungitur in chromatico genere, quod molle vocatur; tonus dividitur in tres partes, ideo tritemoria appellatur. Ipsum vero (chroma) hemiolion, id est diatonum, fit ab hemiolia diesi, id est ab hemitionio, in quo apparet sesquialtera proportio, ejus diesis, quæ fit enarmoni, scilicet generis, quod duæ quartæ partes in enarmonio segregatæ conjunguntur in unum in hemiolio, hoc est in diatono, et efficitur hemiolionum, a quo incipit diatonicum genus, et hemiolon dicitur diatonicum, quod in ipso genere diapente abundat, quæ in extremis suis sonis sesquialtera copulatur ratione.
    
    Sed nunc de tonis, scilicet dicamus. Tonus est spatii magnitudo, id est intervalli inter chordam et chordam, et vocem et vocem; qui ideo tonus dictus est, quod per hoc spatium ante omnes, scilicet voces et divisiones vocum sive chordarum prima vox quæ fuerit, extenditur, hoc est, de nota qualibet in notam, id est, de chorda in chordam, singulæ enim chordæ habent suas notulas, sicut habetur in Bætio; ut a media, scilicet chorda, id est a mese in paramesen, id est in ilham quæ est prope mediam, ut est in Lydio, scilicet sono, si a' iota directo, id est a mese, in signa jacens, id est in paramese signa, id est notulæ concurrant. Verum quod hemiolia diesisque, id est quartæ partis et tertiæ, quando tritemoria vocatur, quid vel quanta quæcunque sint, docui. Proprium etiam nomina, id est, quomodo vocantur, numerumque monstravi, id est, quod sint xv.

    -A que tropi tetrachorda quina cuslodint, sicut superius quoque notavi.) Verum horum, scilicet tetrachordorum extremos, id est primum hypaton, quod ultimum netarum hyperbolëon, sesquitertia enim proportione simibet conjunguntur extremi soni omnium tetrachordorum (sibi aptandos esse non dubium est. Tetrachordium quippe est) quatuor sonorum, id est chordarum, (in ordine positorum congaurenç et) fida concordia, id est inerrata. Sunt autem tetrachorda principium, id est hypaton; mediarium, id est meson; conjunctarum, id est, synemmenon; separatarium, id est diezeugmenon; excellentium, id est hyperbolëon. Et primum tetrachordum, quod est gravis, incipit a principalium principali, id est ab hypate hypaton, et desinit in principale medium, id est hypate meson. Verum principalium et medium, scilicet tetrachordum, id est hypaton et meson connexum, scilicet est, id est conjunctum, quod nihil interest, quod conjunctarum vocatur, scilicet quod jungitur tetrachordo mediarium, erit tetrachordum a media, id est a mese, in neten conjunctarum, id est in neten synemmenon. Atque divisum, scilicet aliud tetrachordum, ab his, scilicet prædictis tetrachordis duobus, longeque discretum, quod est quartum divisarum, a submedia, id est a paramesse, in neten, id est ultimam separatorum, id est in neten diezeugmenon usque jungitur. Separatorum tetrachordum dicitur, quod omnino separatur a mese, cum qua nullam habet consonantiam. Quod autem ex diversis, id est, separatis conjungtum est, id est inchoat, in acutiorem sonum, et in quintum, scilicet tetrachordum, id est in quintam chordam, excellentium, id est hyperbolëon profertur. (Sed de tetrachordis satis dictum. Nunc de pentachordis videamus.)
    
    Ac similiter hæc quoque quinque, id est pentachorda, esse non dubium est. Primum igitur, scilicet pentachordum, quod est gravius, principialium esse dicemus, id est hypaton, quod incipit ab Aqqulsilio, id est a proslambanomenon, et in principiem mediarum, id est in hypaten meson terminatur. Sequens, id est secundum pentachordum, in acumen ejusmodi est, quod constat a principalium extena, id est a lichanos hypaton diatonos, in mediarium illam, id est in meson; quæ in Lydio scilicet tropo iota rectum habet. Tertium autem, scilicet pentachordum, conjunctarum est, id est synemmenon, quod a mediarum extena, a lichanos meson diatonos, in ultimam conjunctarum, id est, in neten synemmenon, ducitur. Quartum vero, scilicet pentachordum, quod per divisionem est, interponitur enim tetrachordorum conjunctarum, nam cæterum conjuncti sunt, a media, id est mese, in tertia divisarum, id est, in trite diezeugmenon, connecti solet.
