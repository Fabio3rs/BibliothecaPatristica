    Nulla enim quæ in hoc mundo hominibus sunt, absque Dei occulto judicio fiunt.
    VERS. 6. — ( Recede paululum ab eo. ) Recede, id est, jam flagella præsents vitæ subtrahe, et bona æternæ quies ostende
    ( Donec oplata veniat, ) quando æternam requiem pro recompensatione sui laboris accipit
    VERS. 7. — ( Lignum habet spem. ) etc. Genus humannum quasi despectum insinuat, quantumque ipsa insensibilia hunc præire videantur. Vel juxta mysticum sensum: Lignum præfertur homini, hic enim homo carnalis qunisque; lignum justus accipitur, qui cum in morte passione afficitur, æternæ vitæ viriditate recuperatur.
    ( Et rami ejus pullulant, ) quia ex passione justi fideles viriditatem vitæ spiritualis accipiunt.
    VERS. 8. — ( Si senerit in terra radix. ) (Ibid.) Radix justi sancta prædilcatiò, quia ab ipsa oritur et in ipsa subsistit: quæ apud corda terrenorum cunctis viribus esse creditur: ( Et in pulvere truncus emoritur, ) quia inter manus persequentium corpus ejus exanimatur.
    VERS. 9. — ( Ad odorem aquæ germinabit, ) etc, Quia per afflatum Spiritus, in electorun cordibus, exemplo sui operis, germen virtutis facit.
    ( Et faciet comam, ) etc. Succiso trunco comam facere, etc., usque ad fecit comam, quia apostoli qui aruerant ad fidem ut prius viruerunt.
    VERS. 10. — ( Homo vero cum mortuus fuerit. ) (Ibid.) Ipsa autem amissio justitiæ homo moritur, veste innocentia in paradiso concessa nudatur, interitu carnis consequente consumitur: ( ubi ergo est, ) qui in ejus amore non est, ubi verum esse est?
    VERS. 11. — ( Quomodo si recedant aquæ de mari. ) Mare mens hominis est, etc., usque ad modo dulcedine prosperitatis replemur.
    VERS. 12. — ( Donec asteratur cœlum non evigiliabit. ) Quia, nisi hujus mundi finis advenerit, humauum genus a somno non evigilabit.
    VERS. 13. — ( Quis mihi hoc. ) Ante Mediatoris adventum ad infernum se descendere sciens, illic conditoris protectionem postulat.
    ( Constituas mihi teclum in quo recorderis mei. ) Adventum Redemptoris ad inferos petit.
    VERS. 14. — ( Putasne mortuus homo rursum. ) Solent justi viri, etc., usque ad ut post forines re-lobet.
    ( Cuncta diebus. ) Qui itaque inmutationem suam tanto desiderio exspectat, quam sit de resurrectione certus insinauit.
    VERS. 15. — ( Vocabis me et ego respondebo. ) Tunc vocanti Deo veraciter respondemus, quando ad summae incorruptionis jussum incorruptibiles resurgemus.

    VERS. 16. — ( Tu quidem gressus, ) etc. Gressus dinumerat, et peccatis parcit: qui subtiliter acta nostra considerat, et tamen hic pœnitentibus misericorditer relaxat.
    ( Dinumerasti, sed parce. ) Dinumerat, dum nos ad singula quæ fecimus defendâ covertit; parcit, quia quæ punivimus, non punit, unde adhuc subdit:
    VERS. 17. — ( Signasti quasi in sacculo, ) etc. (Ibid.) In occulto, etc., usque ad curat quia hic per flagella funditus relaxat.
    VERS. 18. — ( Mons cadens desluit. ) (Ibid.) Duo sunt genera tentationum, etc., usque ad vel longa ac lenta ut Salomonem consumi permitis.
    ( Saxum, ) id est mens justi fertur,
    ( De loco, ) id est, de justitia ad culpam nimio impulsu.
    VERS. 19. — ( Lapides, ) id est fortitudinem, ( aquæ ) assidua blandimenta.
    ( Terra, ) quæ sanctificat.
    VERS. 20. — ( Roborasti eum paululum, ) etc. (Ibid.) Paululum roboratus est homo, quia hic vivendi vires ad modicum accepit; sed in hac brevitate ubi roboratus est, colligit, unde in perpetuitate inveniat; vel ut semper gaudeat, vel ut supplicia non evadat.
    ( Immutabis faciem ejus, et emites. ) Facies hominis, etc., usque ad transire ad æterna nolens cognitur.
    VERS. 21. — ( Sive nobiles fuerint filii. ) Sicut enim hi qui adhuc sunt viventes, mortuorum animæ in quo loco habeantur ignorant: ita mortui carnali-ter vitam in carne positiorum qualiter post eos disponantur, nesciunt.
    VERS. 22. — ( Attamen caro ejus dum vivit dolebit. ) Tribulationem enim carnis hic patiuntur etiam qui spiritualiter vivunt.
    ( Et anima illius super. ) Dignum enim est ut in se semper homo moerores inveniat, qui relicto Creatore in se gaudium quærebcat.
