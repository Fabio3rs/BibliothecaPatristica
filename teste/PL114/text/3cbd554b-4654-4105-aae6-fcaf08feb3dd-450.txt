Misit illum in domum suam, id est revocavit il-
lum ad pristinum mundanae naturae : discensio
Christi de monte, ostendit ejus discensionem e coe-
lis : hic discipuli, ordinem tenent Prophelarum vel
Patriarcharum : turbae inquirentes ab eis, adventum
Christi ostendit : Quod turbae, legem a Prophetis et
Patriarchis conquiriebatur : salutabant eum, hic sa-
lutem pro humilitate intelligitur : qui adtulit filium
suum, ordinem tenet Patriarcharum filius genus
humanum ostendit : per spumam superbiam osten-
dit : per stridorem dentium, per crescere avaritiam,
ostendit discipuli non potuerunt curare : hic disci-
puli figuram tenent Patriarcharum, quia neque Pro-
phetae neque Patriarchae potuerunt curare humanum
genus, nisi veniens Christus suo sanguine redemit
illum, ut ait Propheta frater non redemit, id est
Moyses per legem redemit.

Homo, id est Christus : Ab infantia, id est
prima aetate generis humani : dixit pater infanti ;
Credo, adjuva incredulitate mea, ostendit dixisse, si
deest fides adauge, multum discerpens eum : ostendit
quia quando vidit diabolum erasurem de terra in
fine mundi : tunc datus illi potestas, ut faciat quan-
tum vult propter electos Dei : cum vidit se de uno
quoque hominem per confessionem et poenitentiam
expelli, tunc contra illos plus suscitat vitia et cru-
delissimas impugnationes, factus est velut mortuus :
hic exemplum ostendit purgatum hominem, id est
qui per confessionem et poenitentiam, mortificat se
metipsum : hic videtur duo miracula fecisse Jesus,
a daemono curavit et quasi mortuum suscitavit :
sic suscitavit genus humanum a morte peccatorum,
et liberavit a daemono servitus, per mollam circu-
itus saeculi ostenditur : per asinum munditia peccatorum.

Mergere in mare, id est humiliare se in sacculo per
poenitentiam vel perire in prope rio peccato : quia le-
vius est pro se solo poenam sustinere, quam et alii
a regno Dei disturberint : per vermes ostendit sera
poenitentes, semper comedit illum in poena quia dum
spatium habuit non emendavit, omnis igne saliatur :
per ignem accensio Spiritus sancti intelligitur, quia
sicut omnis caro periit sine sale, ita et omnis homo
sine scientia verbi Dei infatuetur : habete salem in
vobis, id est habete sapientiam Dei in vobis : Venit
in finibus Judae, ostendit in futurum reversos ad fi-
dem Christi Judaeos.

Ultra Jordanem id est ad gratiam baptismi : simile
parvulos venire ad me, hic parvuli tenent figuram
gentium : discipuli qui prohibebant, figuram tene-
nent Judaeorum, camelos per foramen acus non
posset transire, nisi depositis oneriis, sic et Judaei
nisi deposita onera peccatorum, sive divitias non
possunt intrare in regnum Dei : quid reliquit Pe-
trus qui dixit : nos omnia reliquimus, ostendit quia
multum reliquit homo, qui semetipsum postposuit,

Adam: per tres peccavit, id est concupivit praevarica-
vit, superbe egit : ita et Christus tres dies fuit in
sepulcro : similiter et proinde, ter mergitur bonae
sub unda baptismi : unde ait Apostolus consepulti
enim sumus cum Christo per baptismum : in morte
enim ipsius baptizati sumus, qui voluerit in vobis pri-
mus esse : erit omnium servus, hic ostendit doctores
Ecclesiae : caecus tenet figuram gentium, sed ebat juxta
viam, id est juxta fidem.

Clamabat ad Jesum, miserere mei : Moralem sen-
sum, cum incumbemus in oratione, tunc turba fas-
tasuna, mentes fidelium increpant, ut taceant dum
volunt nos excludere ab oratione perseverantibus
nobis : tunc Jesus stans secus nos : stare enim di-
vinitatis est; transire vero humanitatis est : prece-
bit illos vocare, id est per predicationem apostolo-
rum : Vocat gentes ad fidem : projecit vestimenta
sua, id est pristinam conversationem suam : exi-
liens, id est de ignorantia ad scientiam de infidelitate
ad fidem : invenietis pullum alligatum ostendit gen-
tes alligatas, cum culpa peccatorum : super qua
nemo scit, id est ubi nullus doctor praedicavit : sol-
vite et adducite ad me, id est per predicationem ad-
ducite ad fidem, vidit arborem fici, ostendit quia
longe erat fides Judaeorum a Christo.

Non erat tempus forum, id est non erat tempus
Judaeorum ut crederent, quod se indigne judicarerunt,
regnum non sciebat vas transferre per tem-
plum, qui corda fidelium : Non vult Christus aliud
fieri opus, vel transire nisi quod sanctum est : tra-
dit eam colonis, id est custodire legem : totcular, hoc
est templum Salomonis : Aliter ostendit martyrum :
Venit ad synagogam, synagoga saepe custodia ange-
lorum : turrem, hoc est lex : ejecerunt eum extra
vineam, id est de Judaeis ad gentes. Aliter de civitate
Jerusolima in montem Calvariae.

Vidua misit duos nummos, quod est quadrans, per
quos intelligit hominem quadrantem qui se Deo ob-
tulit : quaecumque petieritis, credentes in oratione,
fiet vobis : quomodo sic sanctus Paulus dicit : ter
rogavi Dominum pro stimulo et non recessit a me :
diabolus petiit ut templaret Iob, et permisit eum
Deus; Paulus non est exauditus, ut per ipsum stimu-
lum coronaretur : diabolus exauditus est, ut per ejus
temptationes Iob coronaretur : proinde Apostolus ait,
nescimus quid peccamus, nisi Christum qui interpel-
lat pro nobis : gens adversus gentem, id est paga-
norum adversus Christianorum : Mortaler caro adver-
sus animam : regnum diaboli contra regnum Christi,
vitia carnis adversus spiritum bonae operationis :
terrae motus, id est de infidelitate ad fidem, id est
corpus sive anima audiendi verbum Dei : stantis proter
me in testimonium illis, id est si crediderint testimonium
vestrum erit illis ad vitam, etsi non crediderint erit
illis ad poenam.

De die et hora nemo scit : Nisi pater, ostendit pro
parte corporis, quia corpus Christi Ecclesia est :
quod dicit necessitis tempus, id est exitium uniuscujus-
que sive consummationem saeculi.
